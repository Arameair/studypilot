# Publication Policy

Publication is a deliberate human-reviewed process:

```text
Private source material
→ private draft knowledge note
→ rewrite in the user's own words
→ technical verification
→ publication review
→ explicit human approval
→ creation of a separate public artifact
```

Every public artifact requires deliberate rewriting, technical verification
where applicable, privacy and copyright review, and explicit human approval.
The resulting public note must be a new artifact in a Git history separate from
the private vault.

The following actions are prohibited:

- Moving or copying raw private files directly into the public portfolio.
- Publishing transcripts, recordings, or paid-course assets.
- Publishing automatically or without explicit human approval.
- Resolving publication conflicts silently.
- Sharing Git history between the private and public vaults.
- Changing the private repository to public.

StudyPilot does not yet automate or enforce this process.
