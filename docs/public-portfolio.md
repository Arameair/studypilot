# Public Portfolio Contract

`IT-Knowledge-Portfolio` is a public, employer-facing Obsidian vault with this
required structure:

```text
IT-Knowledge-Portfolio/
├── 00 Portfolio Index/
├── 01 Projects/
├── 02 Procedures/
├── 03 Troubleshooting/
├── 04 Concepts/
├── 05 Labs/
├── 06 Professional Development/
├── Templates/
├── assets/
├── .obsidian/
├── README.md
├── PUBLICATION-POLICY.md
└── .gitignore
```

Allowed public content includes original explanations, verified procedures,
troubleshooting documentation, personally performed labs, project summaries,
original screenshots and diagrams, and sanitized professional retrospectives.

Prohibited content includes transcripts, recordings, substantial copied
instructor wording, paid-course screenshots, answer keys, proprietary lab
files, private reflections, personal assessment attempts, credentials, and
private URLs. The public vault must not contain directories named for
transcripts or recordings.

Public notes require at least:

```yaml
---
visibility: public
status: verified
---
```

Content marked `visibility: private` is invalid for the public portfolio. This
contract is documented now and will be enforced by later application work.
